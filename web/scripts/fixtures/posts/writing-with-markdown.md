## 从结构开始

先写出文章想回答的问题，再用二级标题安排内容。每一节只处理一个主题，读者会更容易跟上。

- 用简短的段落说明想法。
- 使用列表呈现并列信息。
- 把关键步骤写完整，让读者可以复现。

## 呈现具体信息

| 内容 | Markdown 写法 |
| --- | --- |
| 小标题 | `## 小标题` |
| 行内代码 | 一对反引号 |
| 引用 | 在段落前加 `>` |
| 链接 | `[文字](地址)` |

代码块适合保留可复制的命令：

```bash
npm run dev
```
