# 网站导航

参考 [OpenAI API 文档 Quickstart](https://developers.openai.com/api/docs/quickstart) 的左侧导航层级，网站在桌面采用固定240px左栏、顶部工具栏与居中正文，左栏可独立滚动；当前页面高亮，文章入口下显示最近12篇已公开文章，正文保持原阅读宽度和左侧小封面卡片。

1000px及以下收起固定侧栏，通过顶部菜单打开左侧导航抽屉。抽屉采用原生模态对话框，支持关闭按钮、Escape和点按遮罩，打开时锁定背景滚动，导航或切换至桌面尺寸后关闭；浏览器管理焦点限制与返回。搜索、主题、登录及后台入口延续原有能力。

导航仅传递已发布且达到公开时间的文章标题和链接，不传递正文或草稿。站点各页共用同一导航组件、字体及灰阶变量，不添加额外内容小标题。

生产构建、TypeScript和216项隔离回归通过。桌面实测侧栏240px固定、正文768px、文章高亮正确；390px和320px无横向溢出，手机抽屉打开时锁定背景、初始焦点在关闭按钮，Escape关闭后焦点返回菜单，点击简历正确导航并关闭抽屉，深色背景一致。测试后恢复浅色与默认视口，本轮没有手机真机验收。预览曾发现通用按钮CSS覆盖桌面菜单隐藏，组合选择器修复后复验通过，原因在CSS旁记录。
