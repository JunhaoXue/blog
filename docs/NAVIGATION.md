# 网站导航

参考 [OpenAI API 文档 Quickstart](https://developers.openai.com/api/docs/quickstart) 的左栏布局，侧栏只在已公开的真实文章详情页出现；左栏只列本博客已发布且到公开时间的非示例文章，并高亮当前文章，不添加搜索、分类或其他页面入口。桌面左栏固定240px，可独立滚动，正文保持原阅读宽度。首页、简历等页面没有侧栏，全站入口保留在顶部导航。

文章详情页在1000px及以下收起固定侧栏，通过「打开文章列表」按钮展开只含文章链接的抽屉。抽屉采用原生模态对话框，支持关闭按钮、Escape和点按遮罩，打开时锁定背景滚动，导航或切换至桌面尺寸后关闭；浏览器管理焦点限制与返回。搜索、主题、登录及后台入口延续原有能力。

导航仅传递已发布且达到公开时间的文章标题和链接，不传递正文或草稿。站点各页共用同一导航组件、字体及灰阶变量，不添加额外内容小标题。

生产构建、TypeScript和216项隔离回归通过。首页和简历实测没有侧栏及左侧留白；文章侧栏240px、正文768px，仅包含真实文章链接且当前文章高亮。最终版本在390px视口无横向溢出，抽屉仅显示文章链接，打开时锁定背景，Escape关闭后恢复滚动。抽屉基础交互另验过320px、焦点返回及深色模式。测试后恢复浅色与默认视口，本轮没有手机真机验收。预览曾发现通用按钮CSS覆盖桌面菜单隐藏，组合选择器修复后复验通过，原因在CSS旁记录。
