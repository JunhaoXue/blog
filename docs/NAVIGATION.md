# 网站导航

对照 [OpenAI API 文档 Quickstart](https://developers.openai.com/api/docs/quickstart) 实际HTML、PageLayout CSS及TableOfContents组件调整侧栏。左栏218px，容器上8px／左右12px／下24px，链接14px字号、20px行高、上下6px／左右12px内边距、8px圆角，条目间距1px；移除整栏分隔边线并隐藏滚动条，仍可独立滚动。选中与悬停使用浅色8%黑色／深色12%白色的透明灰底。文章为平铺列表，不复刻官方分类层级或添加区块标题，字体沿用本站中英文系统字体。

侧栏仅在已公开的真实文章详情页出现，只列全部已发布且到公开时间的非示例文章，并高亮当前文章；只向客户端传递标题与链接。首页、简历等页面保留顶部导航，没有侧栏与左侧留白。1000px及以下改用只含文章链接的原生模态抽屉，支持关闭、Escape、点按遮罩、背景滚动锁定、焦点返回和桌面断点关闭。

右侧目录宽200px，与正文间距48px，文字14px／20px；条目间距12px、层级缩进12px，左侧2.15px浅色轨道与当前条目实色竖线标记，当前章节不铺整行背景。这些尺寸对应官方目录组件；目录提取本站正文一至六级标题，支持点击定位、滚动高亮，重复标题独立锚点，代码块排除。没有标题不留空栏，不足1280px改为正文前默认收起的目录，点击后自动收起。目录与锚点共用Markdown管线，仅添加属性，正文文字及划线评论偏移保持；详情页无大封面，首页小封面、后台关联与分享图保留。

当前样式版本构建与TypeScript通过，本机1364px浏览器实测左栏218px、链接14px／20px／6px12px／8px圆角，选中灰底8%，右栏14px／20px、48px正文间隔和2.15px竖线且无整行背景，点击章节后锚点与高亮一致。深色主题使用白色12%灰底和浅色竖线，390px抽屉只包含文章链接、无左留白，320px无横向溢出，浏览器无警告或错误；已恢复浅色和默认视口。官方参考页截图连接超时，通过服务器读取公开HTML/CSS/组件源码核对参数，未声称字体文件或完整截图逐像素一致。当前仅CSS调整，不新增低影响测试，既有221项回归由GitHub CI检查。

此前验收发现通用按钮display覆盖桌面菜单隐藏，以及原标题偏移与页面滚动留白累加使目录高亮滞后，均已修复并在CSS旁记录原因。
