# 文章封面

封面由文章独立关联媒体库图片，不写入正文；首页、搜索列表与后台预览使用同一组件，分享卡片也使用该封面，文章详情页不显示大封面。文章列表参考本人提供的图文列表 HTML：桌面左图右文，封面256×144px；640–767px封面208×128px；640px以下采用上图下文，封面铺满内容宽度并保持16:9。图片圆角6px、图文间距桌面24px／手机12px、卡片间距32px，不设外框或内边距；摘要最多两行，桌面标题单行截断，手机标题完整换行，日期与分类在底部并保留标签筛选和阅读时长。整卡链接来自文章标题，分类与标签保持独立链接，避免嵌套链接；无封面的文章直接显示文字，不插入占位图。后台可上传、替换和移除图片，提供图片说明；仍被文章封面引用的图片不可删除。旧文章升级后不自动插入无关示例图。

本次封面使用内置 imagegen 生成，以文章所讨论的两个平台Logo为主体，按本人要求简化并增加沉浸感。原始PNG与用于网站的WebP保存在本机运行资料中，生成原稿和个人媒体不随代码上传。

最终提示词要点：横向16:9；深色无限影棚；两个清晰可辨的品牌Logo并排、同等视觉尺寸；左侧青色与粉色、右侧红色柔和照明；地面微弱反射与自然阴影；大量留白；不加入人物、界面截图、照片拼贴、连线或额外文字。使用内置生成工具，随后仅转换为WebP以减少传输体积。

使用本机可用的 Arial／Helvetica 与中文系统字体，不依赖远程字体；首页、文章与简历共用字体变量。文章卡片标题桌面20px、手机18px，摘要16px／24px行高，底部信息14px／20px行高。浅色与深色继续使用本站灰阶变量。

生产构建、TypeScript与211项隔离回归通过；包括旧库封面字段迁移、无效媒体拒绝、封面持久化、分享图、引用删除保护、过期保存与旧编辑器兼容。桌面浏览器检查首页、文章与简历字体一致、封面实际加载、无横向溢出及控制台错误；截图保存在本机验收目录。当前浏览器的视口覆盖未生效，实际仍为1280px，因此没有将该截图记作手机验收；手机断点和同组件比例已经按源码核对，未进行真机测试。
