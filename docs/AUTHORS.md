# 文章署名与转载声明

文章标题正下方展示作者姓名、公开头像和任职信息，导读位于作者信息之后；作者姓名链接至公开简历，沿用40px圆形照片和既有字体灰阶。任职资料从已发布简历的「工作经历」读取明确标题与时间：「至今」等明确在职条目显示为当前经历，已结束条目标为「曾任职于」，不把过往单位当作当前单位，也不从自由格式介绍猜测任职信息。

署名随公开简历更新；简历撤回时，文章和分享元数据只保留站点原公开作者名，不泄漏草稿姓名、头像和工作资料。文章元数据包含作者名及简历链接。

每篇文章末尾显示「© 作者 · 未经作者允许，不得转载。」。该声明独立于Markdown正文，不改变划线评论的文字或定位。
